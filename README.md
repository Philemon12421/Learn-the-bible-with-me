# 🌍 About Learn With Me

**Learn With Me** is a beautifully designed inspiration platform that delivers:

📖 Daily Bible quotations  
💡 Daily motivational quotes  
🧠 Wise sayings and reflections  

The platform is designed with simplicity and peace in mind — offering clean content, smooth user experience and modern design across all devices.

---

# ✨ Features

## 📖 Daily Bible Quotes
- Different Bible quotation every day
- Clean explanation
- Reflection / prayer section
- Copy and share functionality
- Download verse as image

---

## 💡 Motivation Quotes
- Daily motivational quotes
- Short encouraging insights
- Clean quote card layout

---

## 🧠 Wise Sayings
- Wisdom and life lessons
- Daily rotating quotes
- Minimal and elegant presentation

---

## 📥 Verse Image Download
Generate beautiful quote images instantly.

Features:

✅ High quality PNG  
✅ Social media ready  
✅ Download with branding  
✅ Clean typography  

---

## 📩 Email Subscription
No account required.

Users can:

- Subscribe with email
- Receive inspiration updates
- Enjoy a simple experience

---

## 🎵 Optional Music Experience
Soft peaceful background music.

Features:

- Play / Pause
- Music toggle
- Non-intrusive listening
- Relaxing atmosphere

# 🚀 Installation

Clone the project.

```bash
git clone your-repository-url
```

Install dependencies.

```bash
npm install
```

Run locally.

```bash
npm run dev
```

Build for production.

```bash
npm run build
```
