## 📖 About

**Learn With Me** is a faith-centered daily inspiration platform built by [Drenchack Tech Company](mailto:drenchstudio1@gmail.com). It delivers:

- 📖 **31 Daily Bible Verses** — Each uniquely curated scripture includes a full contextual explanation and a personal reflection prayer, one for every day of the month.
- ✨ **31 Motivational Quotes** — From world leaders, philosophers, and visionaries like Nelson Mandela, Albert Einstein, and Eleanor Roosevelt — each with an actionable insight.
- 🧭 **31 Wise Sayings** — Ancient proverbs from African, Eastern, and Western traditions, explained for modern daily life.
- 🎵 **Ambient Audio Player** — 4 peaceful soundscapes (Soft Chimes, Piano, Rain, Forest) for a calm reading atmosphere.

## ⚡ Getting Started

### Prerequisites
- Node.js 18+
- npm or yarn

### Install & Run

```bash
# Clone the repository
git clone https://github.com/your-username/learn-with-me.git
cd learn-with-me

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

---

## 🚢 Deployment (Vercel)

This project is optimized for Vercel deployment:

```bash
# Install Vercel CLI
npm i -g vercel

# Deploy
vercel --prod
```

Or simply connect your GitHub repository to Vercel for automatic deployments on every push.
